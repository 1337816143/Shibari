# Neutral adult training model v2

- Source: Microsoft Rocketbox `Male_Adult_08`
- Source repository: https://github.com/microsoft/Microsoft-Rocketbox
- License: MIT License, Copyright (c) 2020 Microsoft
- Conversion: FBX to glTF Binary with FBX2glTF 0.9.7
- Geometry: 4,491 uploaded vertices; 7,364 triangles; 80-joint skin
- Runtime pose: fixed standing pose with both arms lowered; the learner cannot alter bones
- Texture tiers: `high` uses 2048 px WebP; `medium` uses 1024 px WebP

The original TGA maps were resized and converted to WebP. Color textures use
sRGB; normal textures stay in linear space. The model remains fully clothed and
is used only as a neutral adult teaching avatar.

The full upstream MIT notice is stored at
`LICENSES/MICROSOFT-ROCKETBOX-MIT.txt` in the repository root.
