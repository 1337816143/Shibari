## 1. 参考产品结论

完整表见 [reference-analysis.md](reference-analysis.md)。最终采用三条主线：

- Animated Knots：单步、前后、循环、调速和低操作成本。
- Knots 3D：360°、缩放、拖动时间和清楚的绳索/背景对比。
- TheDuchy：先学习沟通与风险，再进入技法；安全内容放进相关练习上下文。

明确排除国内资源站常见的付费资源聚合、来源不清转载、按刺激程度引流、高风险内容前置和安全提示只放免责声明等模式。

## 2. 最终产品架构

## 3. 3D 实现方案

- 中性、抽象、完整衣着的成年训练人物由本项目程序化生成，没有外部模型版权风险。
- 7 个绳段使用预校验 Catmull–Rom 样条和一次性 `TubeGeometry`。
- 播放过程仅更新已有几何的 `drawRange`，不在每帧重建网格。
- 活动绳段、完成绳段、绳头、风险区、接触点、操作手提示和解除方向为独立图层。
- 支持 360°、缩放、6 个预设视角、自动跟随、锁定、镜像、人物显隐/透明度、完成绳段显隐和当前绳段聚焦。
- 播放器支持上/下一步、播放/暂停、整课/本步重播、单步循环、拖动、任意步骤、0.25/0.5/1/1.5 倍速和键盘控制。
- 暂停时 Three Canvas 使用按需渲染；播放时才连续渲染。低性能与减少动态效果设备默认使用 SVG 分步图，可手动切回 3D。

## 4. 人物与绳索资源方案

当前人物与绳路全部原创并在 [LICENSES/ASSETS.md](../LICENSES/ASSETS.md) 登记。Phase 2 若替换为 GLB：

1. 委托/自制低面数中性成年训练模型，不采购来源不清素材；
2. 保留 Blender 源文件、委托授权、纹理来源、导出参数和哈希；
3. 每个课程姿势单独校验，禁止用户自由改姿势；
4. 使用 Meshopt/Draco、KTX2、LOD 与按课程加载；
5. 任何体型或姿势变体都需重新校验绳路穿模和接触位置。

## 5. 性能结果

测试环境：Node 24.14，生产构建；数值用于技术基线，不等同于真实设备 FPS。

| 项目 | 结果 |
| --- | --- |
| 首页基础 JS | 236.16 kB / 77.29 kB gzip |
| CSS | 46.14 kB / 10.45 kB gzip |
| 3D 代码 | 964.81 kB / 262.18 kB gzip，进入课程才加载 |
| 课程播放器逻辑 | 30.00 kB / 9.76 kB gzip |
| 生产构建耗时 | 0.86 s |
| 中画质绳路 | 7 段、4,095 顶点、7,168 三角形、约 170 KiB 几何数据 |
| 中画质几何创建 | 20 次采样中位数 1.34 ms |
| 70,000 次 `drawRange` 更新 | 0.33 ms（Node CPU 基准） |

高画质绳路为 10,752 三角形，仍远低于人物资产通常占用；后续 GLB 必须把完整场景预算和 GPU 帧时纳入 CI 外的实机基准。当前不能在缺少同设备、同浏览器、同课程条件时声称已客观超过 Knots 3D。

## 6. 桌面与手机测试

已完成：

- TypeScript 严格编译；ESLint 零警告；6 个测试文件、13 个测试全部通过。
- 响应式布局覆盖 >1180、960、700 三档：播放器从左右双栏转为上下结构；视角/图层/步骤控件可横向滚动；手机端操作按钮保留可点击尺寸。
- `prefers-reduced-motion` 自动进入简化模式；WebGL、核心数与设备内存参与画质分级。
- GitHub Pages 子路径 `/Shibari/` 生产构建成功，Hash 路由不依赖服务器回退。
- 公开 Pages 已在 1363 × 936 桌面视口完成视觉与 DOM 检查：首页、课程、练习室、安全、路径、课程库、进度和术语页面均可加载，页面无横向溢出、重复 ID、无替代文本图片或无可访问名称按钮。
- 公开预览已验证播放/暂停、步骤跳转、1.5 倍速、镜像、视角锁定、图层开关、透明度、完成步骤、复习标记、备注、收藏、本地进度回显以及课程搜索/筛选。
- 测试浏览器禁用 WebGL 时，页面能识别能力并保留 SVG 分步图；实测发现并修复了“强制启用 3D 后空白”的兼容性问题，现在 3D 按钮会禁用并说明降级原因。

尚未完成：当前远程浏览器不提供移动视口切换且禁用 WebGL，因此 390 px 真机渲染、触控旋转和真实 GPU 帧时仍不能标记为已验证。合并前仍需使用真实 Chrome/Edge/Safari 与 iOS/Android 设备补测；源代码中的响应式断点与低性能降级已通过构建和单元测试，但不冒充实机结果。

## 8. 已知限制

- 示范课是技术验证，尚无合格绳艺教师或相关专业人员审核；页面不会将其标为正式课程。
- 程序化人物适合验证交互，但不具备 GLB 蒙皮、体型变体与真实衣物褶皱。
- 操作手以提示点和文字呈现，尚未制作完整手部关键帧动画。
- 快速解除已有方向层与步骤说明，但尚无逐段逆向解绳/安全剪切动画。
- 无实时绳索物理；这是为了路径确定性和性能稳定而有意保留的边界。
- 仅有一门示范课；课程数量必须让位于准确性与审核。
- 桌面公开预览已完成首轮浏览器测试；真实 GPU、手机触控、Safari 和完整辅助技术测试仍需人工实机完成。
