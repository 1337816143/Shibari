## 为什么替换

Phase 1 的程序化胶囊体只用于验证绳索坐标、相机和播放器。它缺少真人比例、脸部、手指、衣物褶皱与可信材质，不足以承担局部接触位置教学。当前版本不再把它作为中高性能设备的主模型。

## 处理与渲染

1. 使用 FBX2glTF 0.9.7 将上游 FBX 转换为 glTF Binary。
2. 将颜色、法线和透明纹理由 2K TGA 转换为 WebP；保留 2K 高画质和 1K 中画质两档。
3. 颜色纹理按 sRGB 解释，法线纹理保持线性空间；人物使用独立身体、头部与透明裁切 PBR 材质。
4. 高画质启用程序化环境反射、2K 阴影、三点灯光、软接触阴影与较高各向异性过滤。
5. 中画质使用 1K 纹理与 1K 阴影；低画质保留原创程序化模型；无 WebGL 时继续使用 SVG 分步图。

## 固定姿势与坐标校验

人物不允许用户自由改变骨骼。运行时只应用课程预设的双臂下垂姿势，并保持所有其他骨骼不动。

在课程变换 `position = [-0.48, -0.27, 0]`、`scale = 1.8` 下，画面左侧腕骨参考点为 `[-0.8887, 1.2990, -0.0357]`。现有绳圈的主要坐标范围以 `x ≈ -0.86`、`y = 1.23–1.32` 为中心，因此无需通过每帧修正或实时物理强行贴合。

## 仍需人工检查

- 在真实 WebGL/GPU 设备逐视角确认手腕、衣袖、绳圈与风险覆盖层没有穿模或遮挡。
- 在 390 px 手机、Safari 和中低端 Android 设备确认首次加载、纹理显存与触控旋转。
- 由合格绳艺教师确认衣物覆盖情况下的接触位置表达是否足够清楚。
- 只有通过上述检查后，模型版本才能从视觉技术验证进入正式课程资产。
