# Phase 2 技术进展

日期：2026-08-02  
分支：`agent/3d-learning-poc`  
状态：技术实现完成，内容仍为 `technical-review`

## 本轮目标

Phase 2 不新增未经审核的课程，先补齐第一门示范课的解除教学能力，并确保该能力可以由后续课程数据复用。

## 已实现

- 在统一 `Course` Schema 中加入 `releasePlan` 和数据驱动的解除阶段。
- 每个解除阶段包含时长、涉及绳段、操作说明、方向、张力、检查点、风险、沟通节点与推荐镜头。
- 通用绳索引擎按解除阶段反向缩短现有 `TubeGeometry`，不会每帧重建网格。
- 同一解除播放器支持播放、暂停、时间轴、阶段跳转、上一步、下一步、重新演练与 0.25/0.5/1/1.5 倍速。
- 3D 不可用时，SVG 简化模式保留完整的解除阶段、文字与时间轴，不产生空白教学区。
- 解除模式使用独立青绿色高亮、方向提示、自动镜头和阶段说明面板。
- 课程校验会拒绝未知/重复/遗漏绳段、未知镜头、非法时长以及缺失安全文字的解除数据。

## 安全边界

- 当前解除路径与措辞尚未经过合格绳艺教师复核，因此仍明确显示“技术演示 · 待审核”。
- 页面持续说明：出现异常时不要等待动画，也不要为了逆向解绳而延误快速解除。
- 本轮只演示非紧急、地面、松弛状态下的逆向绳段显示；没有制作可能造成误导的安全剪切割动画。
- 课程不会进入 `expert-review` 或 `published`，也不会扩展悬吊、颈部受力、呼吸限制等高风险内容。

## 当前验证结果

- ESLint 零警告、TypeScript 严格编译通过；6 个测试文件共 17 项测试通过。
- 生产构建通过；基础入口为 240.96 kB（78.93 kB gzip），课程播放器为 37.85 kB（11.41 kB gzip）。
- 解除动画复用现有几何，绳路仍为中画质 7,168 个三角形、约 170 KiB；本轮没有增加 3D 网格数量。
- 中画质几何创建中位数 1.30 ms，70,000 次 `drawRange` 更新约 0.37 ms（Node CPU 技术基线）。
- `npm audit --omit=dev` 为 0 个生产依赖漏洞。

## 进入专业审核前仍需完成

1. 在支持 WebGL 的真实设备逐帧检查逆向绳段、穿模、镜头遮挡和触控操作。
2. 由合格绳艺教师确认每个解除阶段、先后关系、用词和安全剪切换条件。
3. 根据审核结果调整控制点和阶段，不把当前技术草案直接作为正式教学内容。
4. 增加经审核的手部关键帧；安全剪动画只有在切割通道和表达方式通过审核后才制作。
