# Phase 1 参考产品分析

调研日期：2026-08-02。仅分析无需登录即可访问的公开页面和官方产品说明；没有抓取、保存或复用任何付费图片、视频、模型与课程文字。

## 体验与信息结构对比

| 产品 | 课程 / 分类 | 单课与分步 | 动画 / 3D | 安全与进度 | 移动端 / 性能 |
| --- | --- | --- | --- | --- | --- |
| [捆绑术](https://www.kunbangshu.cn/) | 简单、中级、高级、图书和会员资源并列，路径依赖难度标签 | 卡片指向图片/视频/下载资源，步骤一致性弱 | 无统一播放器或 3D 视角 | 安全内容没有成为课程门槛；会员/价格信息强于进度 | 信息密度高、营销区块多，首屏认知负担大 |
| [绳师48号](https://www.ishibari.cn/) / [基础课程](https://www.ishibari.cn/jichukecheng/) | 基本、简单、中级、高级与文章混排 | 图文/视频资源条目为主，单节页缺少统一结构 | 无统一可交互 3D | 有零散基础文章，但风险未逐步绑定；依赖账号/VIP | 卡片可浏览，但资源站结构在手机上较长 |
| [绳艺画](https://www.ksbada.com/) | 以审美视频与内容流为主 | 视频消费强于技能拆解 | 无可验证的逐步 3D | 学习路径、安全检查与能力前置弱 | 适合浏览，不适合练习时反复定位某一步 |
| [Animated Knots](https://www.animatedknots.com/) | 按用途和结型分类，搜索明确 | 单结页包含用途、优缺点、逐帧动画和说明 | 2D 定格动画；可前后步进、循环、调速、镜像 | 会陈述具体失效方式；无身体风险层或系统化进度 | 控件直接、加载轻，移动端练习成本低 |
| [走天涯绳结](https://knots.zoutianya.com/) | 轻量绳结目录 | 页面短、适合作为速查 | 以独立绳结展示为主，无人物 3D | 通用提示有限，无课程进度 | 轻量，但教学深度和交互都有限 |
| [Knots 3D](https://knots3d.com/zh-CN/%E7%BB%B3%E7%BB%93) | 200+ 绳结，按活动、结型、搜索与收藏分类 | 逐步动画 + 用途说明 | 360°、缩放、暂停、速度、时间方向；聚焦独立绳结 | 通用高风险警告；新版 App 有最近查看、笔记、自定义分类 | 3D 交互清楚；模型库体积大，网页上下文弱于 App |
| [TheDuchy](https://www.theduchy.com/getting-started/) | 先“场景/沟通/风险/材料”，再进入基础结与技法 | 图文步骤、课程串联、前置关系较完整 | 主要为图文/视频，缺少自由视角 3D | 风险管理优先，且把安全知识分散到相关练习上下文 | 内容可信感强，但长页面和会员层增加查找距离 |
| [Shibari Study](https://shibaristudy.com/) | 教师与主题驱动的在线视频课程库 | 高质量视频课与课程系列 | 视频视角固定，无法检查被遮挡绳路 | 教师背书较强；学习依赖订阅与视频观看 | 视觉成熟，视频带宽、付费门槛和回看定位是成本 |
| [NetKnots](https://www.netknots.com/) | 180+ 绳结，按钓鱼、航海、户外等用途细分 | 动画、插图、逐步文字同页 | 2D 动画可暂停和回退 | 会说明结的限制；无身体层安全和学习路径 | 轻、搜索直接，但页面内容/广告密度高且不支持空间视角 |

## 借鉴与排除

| 决策 | 借鉴 | 不采用 |
| --- | --- | --- |
| 学习路径 | TheDuchy 的“沟通与风险先于技法”；用前置技能控制推荐 | 只用简单/中级/高级，或把高风险内容放在首页吸引点击 |
| 播放器 | Animated Knots 的单步、循环、键盘操作；Knots 3D 的 360°、缩放和自由拖动 | 只有起点/终点、无法停在关键穿绳处的自动视频 |
| 课程页 | 3D、当前步骤、时间轴三者同屏；说明随步骤切换 | 长图文与视频分离，用户在练习时来回滚动 |
| 安全 | 每步绑定风险区、沟通点、检查点和解除方向；状态异常立即停止 | 只在页脚放免责声明，或用“两指测试”宣称绝对安全 |
| 视觉 | 中性成年训练模型、清楚配色、当前绳段优先 | 色情化姿势、裸露模型、高刺激营销和会员弹窗 |
| 内容 | 原创数据、原创程序化模型、审核状态和版本可追溯 | 聚合来源不明的付费教程、转载图书/视频或复制参考站文字 |

## 结论

产品差异点不是“再做一个教程库”，而是把 Knots 3D 的空间可读性、Animated Knots 的逐帧控制和 TheDuchy 的风险优先路径，组合到“绳索与成年人体接触”的具体语境中。第一阶段只验证一门地面、非负重、低复杂度示范课；未完成人工审核前不扩充课程数量。
