# 课程数据 Schema

权威类型定义位于 `src/types/course.ts`，运行前一致性检查位于 `src/lib/courseValidation.ts`。以下是内容团队与 3D 制作团队共同使用的字段分组。

| 分组 | 核心字段 | 消费者 |
| --- | --- | --- |
| 基本信息 | `id`、`slug`、标题、简介、阶段、部位、技法、时长、伙伴需求 | 课程库、搜索、详情页 |
| 前置与材料 | `prerequisites`、绳材、直径、长度、数量 | 路径推荐、课程准备区 |
| 适用与风险 | `scope`、`contraindications`、`prohibitedAreas`、`stopSymptoms` | 安全闸门、详情页、步骤面板 |
| 审核与版本 | `review.status`、`reviewers`、`version`、`updatedAt`、`sources` | 发布闸门、版本追踪、页面徽章 |
| 人物与姿势 | 模型 ID、实现方式、GLB/纹理仓库路径、位置、比例、姿势 ID、来源、许可、成年/完整衣着约束 | 3D 资产加载器、许可审计 |
| 镜头 | 预设 ID、位置、目标、FOV、是否特写 | 视角控制、自动跟随 |
| 绳路 | 分段 ID、样条控制点、出现区间、接触区域 | 通用绳索渲染器 |
| 安全图层 | 风险区位置/尺寸/严重度、接触点、绳头与解除方向 | 3D 安全叠加层 |
| 动画步骤 | 时间区间、活动绳段、推荐镜头、操作手 | 播放器、时间轴、场景状态 |
| 每步文字 | 目标、起点、路径、方向、松紧、检查点、错误、风险、沟通 | 右侧步骤面板 |
| 快速解除 | `releasePlan`、阶段时长、逆向绳段、方向、张力、检查点、风险、沟通、安全剪位置 | 解除播放器、阶段面板、3D/SVG 叠加层 |

## 自动检查

- 步骤 ID 唯一，顺序连续，时间区间从 `0` 连续覆盖到 `1`。
- 所有步骤引用的绳段与镜头必须存在。
- 样条至少包含两个控制点，显示区间合法。
- 每个教学步骤必须同时提供目标、起点、路径、方向、松紧、沟通、检查点、错误和风险。
- 解除阶段顺序与时长必须合法；引用的镜头和绳段必须存在，每个绳段在解除计划中恰好出现一次。
- 每个解除阶段必须提供操作、方向、张力、检查点、风险和沟通文字；课程必须有解除方向标记、免责声明和紧急处理说明。
- GLTF 人物只能引用仓库内的安全相对路径，必须记录来源、来源链接、许可证与正数显示比例。
- `published` 课程必须至少有一名具名审核人；当前示范课因此不能误标为正式发布。
